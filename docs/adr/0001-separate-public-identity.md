# Thelemina is a public identity separate from any legal name

Everything published from this repo (the site, its commits, and the Works it links to) is signed as Thelemina and published under the `thelemina418` GitHub account. Nothing links back to a legal name or a professional portfolio. Moving repos into an org wouldn't have been enough, because commit history keeps author names and emails and new commits link to the committing account. So existing public projects (Lem Reader, FlowSynth) are republished under `thelemina418` with authorship rewritten, and the originals are made private.

## Consequences

- Commit SHAs of migrated projects change; old clones and forks keep the old history. Accepted, since these are solo projects.
- Agents working in this repo must commit as Thelemina with a noreply address, and must never write identifying personal details (legal name, personal email, the origin of the name) into tracked files.
